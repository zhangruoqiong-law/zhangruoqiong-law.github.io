# 短视频脚本模板

## 平台选择
- 抖音：最大流量池
- 视频号：微信生态，直接引流到微信
- 小红书：法律知识图文

## 视频类型

### 类型1：法律知识快讲（60秒）
场景：律师正装出镜，直接讲知识点

脚本模板：
```
[开场 0-5秒]
发生交通事故后，90%的人第一步就做错了！

[正文 5-45秒]
做对这三步，理赔金多拿不止一点点：
第一，立即拍照取证，车牌照、碰撞点、路面标线全拍进去
第二，打122报警，等交警出事故认定书
第三，48小时内给保险公司报案

[结尾 45-60秒]
我是张若琼律师，有法律问题关注我，免费咨询。
```

### 类型2：案例故事（90秒）
场景：口述 + 字幕 + 相关图片

脚本模板：
```
[悬念开头 0-8秒]
被公司辞退还拿不到赔偿？我代理的这个案子，最后拿了2N赔偿。

[案情 8-30秒]
当事人在公司干了5年，休完产假回来就被辞退了...

[法律分析 30-70秒]
根据劳动合同法第42条，女职工在哺乳期内，公司不能随意辞退...

[结果+引导 70-90秒]
最后仲裁支持了2N赔偿。如果你也遇到类似情况，可以找我咨询。
```

### 类型3：法律辟谣/干货清单（45秒）
场景：快节奏剪辑 + 文字弹窗

## 拍摄设备
- 手机即可（iPhone/安卓旗舰）
- 补光灯（淘宝100元以内的环形灯）
- 领夹麦克风（100元左右）

## 发布频率
每周3-5条，固定时间发布（如每晚8点）
